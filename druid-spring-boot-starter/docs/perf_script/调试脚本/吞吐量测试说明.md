# 吞吐量测试说明

## 更新内容

已将 JMH 性能测试更新为包含**吞吐量模式**，现在可以同时测量：

1. **吞吐量 (Throughput)** - 每毫秒操作数 (ops/ms)
2. **平均耗时 (AverageTime)** - 每次操作耗时 (ms/op)

## 使用方法

### 自动化测试

```bash
cd 调试脚本
python auto_jmh_test.py
```

**测试时间**: 约 2-3 分钟（两种模式）

**输出目录**: `性能测试结果/YYYYMMDDHHMM/`

## 报告内容

### 性能摘要

| 指标 | 说明 |
|------|------|
| **吞吐量** | 每毫秒可执行的操作次数 |
| **平均耗时** | 每次操作的平均耗时 |
| **误差范围** | 测试结果的误差范围 |

### 示例输出

```
性能摘要:
------------------------------------------------------------
Benchmark                                                  Mode  Cnt    Score      Error  Units
CustomerOutputVisitorUtilsBenchmark.testGetSqlTemplate_v2  thrpt    5     X.XXX ± Y.YYY  ops/ms
CustomerOutputVisitorUtilsBenchmark.testGetSqlTemplate_v2  avgt     5     Z.ZZZ ± W.WWW  ms/op
------------------------------------------------------------
```

## 吞吐量说明

- **单位**: ops/ms (每毫秒操作数)
- **数值越高越好**: 表示每秒可以处理更多操作
- **换算**: ops/ms × 1000 = ops/s (每秒操作数)

## 与平均耗时的关系

吞吐量和平均耗时是互相关联的：

- 如果平均耗时是 0.29 ms/op
- 那么吞吐量约为 3.45 ops/ms (1000 ÷ 0.29)
- 约等于 3450 ops/s

## 测试模式对比

| 模式 | 单位 | 说明 | 越大越好 |
|------|------|------|----------|
| **Throughput** | ops/ms | 每毫秒操作数 | ✅ 是 |
| **AverageTime** | ms/op | 每次操作耗时 | ❌ 否 |
